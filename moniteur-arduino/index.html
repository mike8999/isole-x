Câble USB (ordinateur)

  1. Téléverse le programme avec l'IDE Arduino, puis ferme le moniteur série de l'IDE (un seul logiciel à la fois peut utiliser le port).
  2. Choisis la vitesse en haut de la page : la même que Serial.begin() (9600 par défaut).
  3. Clique sur Connecter l'Arduino et choisis le port (souvent « USB-SERIAL CH340 » ou « Arduino Uno »).

Bluetooth avec un module HC-05 ou HC-06 (Android ou ordinateur)

Câblage sur une Uno :

  • VCC → 5 V, GND → GND
  • TXD du module → D10 de l'Arduino
  • RXD du module ← D11 de l'Arduino par un pont diviseur (1 kΩ en série, 2 kΩ vers GND) : le module accepte 3,3 V, pas 5 V
  1. Téléverse le programme Bluetooth. Le module clignote vite : il attend une connexion.
  2. Dans les réglages Bluetooth du téléphone (ou de l'ordinateur), associe le module « HC-05 » ou « HC-06 » (code 1234 ou 0000).
  3. Dans la page, vitesse 9600, puis Connecter l'Arduino et choisis le module dans la liste.

Android : Chrome à jour (version 148 ou plus). Sur ordinateur, le module associé apparaît comme un port série de plus.

Wi-Fi avec un ESP32 (tous les téléphones, iPhone compris)

L'ESP32 crée son propre réseau Wi-Fi et contient cette page. Pas besoin d'Internet ni du réseau du lycée.

  1. Dans l'IDE Arduino, installe les cartes « esp32 by Espressif » (gestionnaire de cartes), puis téléverse le programme ESP32. Change le nom du réseau si plusieurs groupes travaillent dans la même salle.
  2. Sur le téléphone, connecte-toi au Wi-Fi Moniteur-ESP32 (mot de passe A_REMPLACER). Si le téléphone dit « pas d'accès Internet », choisis de rester connecté.
  3. Ouvre http://192.168.4.1 dans le navigateur : les mesures s'affichent toutes seules.

Câblage : capteurs sur GPIO 34, 35 et 32 (entrées de l'ADC1 uniquement, car l'ADC2 ne fonctionne pas quand le Wi-Fi est actif), alimentés en 3,3 V. Valeurs brutes de 0 à 4095 : prends les conversions « ESP32 » dans ⚙.

Si la page ne s'ouvre pas : coupe les données mobiles du téléphone, il essaie sinon de passer par la 4G. Le même programme envoie aussi les mesures par câble USB, à 115200 bauds.

Programme ESP32 Wi-Fi (.ino, contient la page)

Ce que la carte doit envoyer

Une ligne par mesure (Serial.println à la fin). Plusieurs voies : valeurs séparées par des points-virgules. Le nom devant la valeur est facultatif.

512
23.5;512;1
Temp:61;Pot:512;Lum:730

Le format du traceur série de l'IDE Arduino (valeurs séparées par des virgules ou des espaces) est aussi accepté. Avec des points-virgules, la virgule décimale est acceptée (23,5).

Conversion de la valeur brute

analogRead() donne un nombre entre 0 et 1023 sur une Uno (0 à 5 V), entre 0 et 4095 sur un ESP32 (0 à 3,3 V). Le bouton ⚙ de chaque voie le convertit en grandeur physique avec grandeur = a × brut + b : choisis un capteur dans la liste, entre a et b, ou calcule-les à partir de deux points de mesure connus.

Si ça ne marche pas

  • Le port n'apparaît pas : installe le pilote CH340 (cartes compatibles Arduino), change de câble USB (certains ne font que la charge). En Bluetooth : associe d'abord le module dans les réglages.
  • « Impossible d'ouvrir le port » : le moniteur ou le traceur série de l'IDE est encore ouvert, ou un autre onglet utilise la carte.
  • Caractères bizarres dans « Données reçues » : la vitesse ne correspond pas à Serial.begin().
  • Firefox, Safari et les iPhone ne gèrent pas la liaison série : passe par le Wi-Fi avec un ESP32.

Sans Arduino, le mode démo simule trois capteurs pour essayer la page.
