Comment ça marche

Créez les postes

Rangez-les par catégorie (accueil, buvette, logistique…) avec les horaires et le nombre de personnes nécessaires.

Ajoutez l'équipe

Tapez les prénoms de vos bénévoles. Pas de compte à créer, ni pour vous ni pour eux.

Posez les jetons

Glissez chaque bénévole sur un poste. Les postes complets passent en doré, ceux qui manquent de monde sautent aux yeux.

Pensé pour le jour J

  • Sur tous les téléphones, même anciens (dès l'iPhone 8), et sur ordinateur.
  • Un seul lien à partager : toute l'équipe voit le même planning à jour.
  • Plusieurs événements : dupliquez l'équipe et les postes pour le suivant, gardez les anciens.
  • Export Excel et impression pour afficher le planning sur place.
  • Code cadenas pour protéger les actions importantes (supprimer, créer un événement).
  • Installable sur l'écran d'accueil comme une vraie application.

Questions fréquentes

Mes bénévoles doivent-ils installer quelque chose ?

Non. Ils ouvrent le lien dans leur navigateur. Ceux qui le souhaitent peuvent l'ajouter à leur écran d'accueil.

Que deviennent les données ?

Seuls les prénoms (et, si vous le voulez, un téléphone) sont enregistrés, pour votre événement uniquement. Ils ne sont jamais revendus et sont supprimés à votre demande.

Peut-on l'essayer avant de payer ?

Oui : les associations pilotes l'utilisent gratuitement pendant la saison de lancement.
