# Isole x !

Jeu web pour apprendre à isoler une inconnue, dans un univers d’établi / fablab.

- Page d’accueil : choix de la spécialité (SI, STI2D SIN, ITEC, EE, AC)
- Chapitres communs : addition, multiplication/division, équations mixtes, développer/factoriser
- Formules propres à chaque spécialité, progression et couleur par spécialité
- Générateur aléatoire, indices, annulation, traduction en équation pas à pas

En ligne : https://mike8999.github.io/isole-x/
